Fuga de Datos

Seguridad en Profundidad
9 invariantes obligatorias verificadas por tests
  • RBAC departamental — JWT con accessible_departments
  • Rate limiting — 5 login/min por IP
  • CSP + Security Headers — XSS, clickjacking, MIME sniffing
  • Password OWASP — ≥8, mayús, minús, dígito, especial
  • SHA-256 en memoria — anti-duplicados + integridad
  • Auditoría inmutable — Trigger SQL que bloquea UPDATE/DELETE
  • Anti-enumeración — mismo error para user inexistente o pass incorrecta
  • No-root containers — todos los servicios con usuario no privilegiado
  • XSS sanitization — DOMPurify en toda salida RAG
Cada invariante tiene un test que intenta violarla deliberadamente.
Funcionalidades Clave
Del login a la respuesta adaptada, todo en un flujo continuo
1. Login seguro

Cookie httpOnly + SameSite=Lax. Rate limiting 5/min.

2. Subida de documentos

SHA-256 en memoria, magic bytes %PDF, 10 MB máx.

3. Gestión de usuarios

CRUD completo por admin. Roles: admin, lead, staff.

4. Consulta RAG adaptada

Selección de audiencia. Contexto filtrado por departamento.

5. Respuesta inteligente

Markdown renderizado + sanitizado. Cita fuentes.

6. Auditoría completa

Cada acción registrada en log append-only.
